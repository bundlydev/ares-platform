# Single example of how to works the Webhook System

## How to use

### Deploy Ares Platform Services

Start by deploying the core services of the Ares Platform from the root directory, following the instructions provided in the main README.md.

### Deploy This Project

Deploy this example project using the command:

```bash
dfx deploy
```

### Register the Canister

After deploying, copy the `Principal` of this canister and register it in the Webhooks section of the Ares Platform.

### Trigger Events

Perform actions that modify the state of any module in the Ares Platform, and observe the logs generated by the webhook listener.

## How it works

To register a canister as a listener for events in the Ares Platform, it must implement a `callback` method with the following specification:

```motoko
public shared func callback(event : WebhookTypes.Event) : ()
```

Where `WebhookTypes.Event` can be imported from the `workspaces` canister and is located in its `webhooks module`.
